%%%%%%%%%%%%%%%%% Article abstract  %%%%%%%%%%%%%%%%%%%%
\noindent{\bf Abstract:}\\
	This paper proposes an MCP-penalized approach for variable selection in time-dependent Cox regression models with counting-process data. The proposed algorithm enables efficient estimation in moderate- and high-dimensional settings. Simulation results show that MCP substantially reduces false negatives and is computationally more efficient than LASSO. An analysis of the Mayo Clinic PBC dataset further demonstrates that MCP achieves predictive performance comparable to LASSO while requiring less computation time and producing less shrinkage of important covariate effects.
	
	
	
\noindent{\bf Keywords:} 
Time-Dependent Cox Model, Minimax Concave Penalty (MCP), Variable Selection, and Counting-Process Data. \\

\section{Introduction}
The Cox proportional hazards model \cite{cox1972regression} is one of the most widely used methods for analyzing survival data. In many contemporary applications, a large number of covariates are collected, making variable selection essential for improving model interpretability and prediction accuracy. Moreover, in numerous longitudinal studies, covariate values evolve over time and should be appropriately incorporated into the analysis through time-dependent Cox models. Recent developments have investigated efficient estimation strategies and computational approaches for time-dependent Cox models under different estimation frameworks \cite{Ramezani2026a}.

Penalized regression techniques have become important tools for variable selection in high-dimensional survival analysis. Among these methods, the least absolute shrinkage and selection operator (LASSO) \cite{tibshirani1996regression} has been extensively studied because it simultaneously performs coefficient estimation and variable selection. Efficient computational algorithms have also been developed for LASSO-penalized Cox regression \cite{simon2011regularization,Ramezani2026b}. However, LASSO is known to introduce substantial shrinkage bias for large regression coefficients and generally does not satisfy the oracle property \cite{fan2001variable}.

To overcome these limitations, folded-concave penalties have been proposed as attractive alternatives. In particular, the minimax concave penalty (MCP) \cite{zhang2010nearly} reduces the estimation bias associated with LASSO while retaining sparsity in the estimated model. Bradic et al. \cite{bradic2011regularization} established a theoretical framework for folded-concave penalization in high-dimensional Cox regression. However, their work primarily focused on standard Cox models, and the practical performance of MCP under time-dependent covariate structures remains relatively unexplored.

Motivated by these considerations, this study investigates MCP-penalized estimation for time-dependent Cox models using a Local Linear Approximation (LLA) algorithm based on the penalized Breslow partial likelihood. The performance of MCP is compared with that of LASSO through simulation studies and a real data application. The competing methods are evaluated with respect to variable selection accuracy, estimation bias, variability of coefficient estimates, mean squared error, and computational efficiency.

The main contributions of this work are threefold. First, we develop an efficient computational procedure for MCP-penalized estimation in time-dependent Cox regression models. Second, we conduct a comprehensive empirical comparison between MCP and LASSO under various simulation settings. Third, we assess the estimation accuracy and variable selection performance of the competing methods, providing practical insights into the use of MCP for time-dependent survival analysis.


\section{Methodology}

\subsection{Time-Dependent Cox Model}
Let $T_i$ denote the survival time and $C_i$ the censoring time for the $i$-th subject, $i = 1, \ldots, n$. We observe $(Y_i, \Delta_i, \boldsymbol{X}_i(t))$, where $Y_i = \min(T_i, C_i)$ is the observed time, $\Delta_i = I(T_i \leq C_i)$ is the event indicator, and $\boldsymbol{X}_i(t)$ is a $p$-dimensional vector of possibly time-dependent covariates.

The time-dependent Cox proportional hazards model is defined as
\[
h(t \mid \boldsymbol{X}_i(t)) = h_0(t)\exp\big(\boldsymbol{X}_i(t)^\top \boldsymbol{\beta}\big),
\]
where $h_0(t)$ is an unspecified baseline hazard function and $\boldsymbol{\beta} = (\beta_1, \ldots, \beta_p)^\top$ is the vector of regression coefficients.

The partial likelihood estimator is based on the Breslow-type partial log-likelihood:
\[
\ell^{B}(\boldsymbol{\beta})
=
\sum_{i=1}^{n}
\Delta_i
\left[
\boldsymbol{X}_i(t_i)^\top\boldsymbol{\beta}
-
\log
\left\{
\sum_{j\in\mathcal{R}(t_i)}
\exp\left(
\boldsymbol{X}_j(t_i)^\top\boldsymbol{\beta}
\right)
\right\}
\right],
\]
where $\mathcal{R}(t)$ denotes the risk set at time $t$. The function $\ell^{B}(\boldsymbol{\beta})$ is concave in $\boldsymbol{\beta}$, but in high-dimensional settings it leads to unstable estimates, motivating the use of penalized likelihood approaches.




\subsection{MCP Penalty and Theoretical Remarks}
\label{subsec:mcp_theory}

Penalized estimation is based on maximizing $Q(\boldsymbol{\beta})
=
\ell^{B}(\boldsymbol{\beta})
-
\sum_{j=1}^{p}
p_{\lambda}(|\beta_j|)$, where $p_{\lambda}(\cdot)$ is a penalty function indexed by the tuning parameter $\lambda$. Following \citet{bradic2011regularization}, the scaled penalty is defined as
$\rho(t;\lambda)
=
\lambda^{-1}p_{\lambda}(t).$
A penalty is said to be folded-concave if $\rho(t;\lambda)$ is increasing and concave on $[0,\infty)$ and has a continuous derivative satisfying $\rho'(0^+;\lambda)>0$.

In this study, we focus on the Minimax Concave Penalty (MCP) proposed by \citet{zhang2010nearly}, defined as
$p_{\lambda}(t)
=
\lambda
\int_{0}^{t}
\left(
1-\frac{x}{\gamma\lambda}
\right)_+
dx,
\quad t\ge0,
$
where $\lambda>0$ is the regularization parameter and $\gamma>1$ controls the degree of concavity. The corresponding derivative is
$
p_{\lambda}'(t)
=
\lambda
\left(
1-\frac{t}{\gamma\lambda}
\right)_+.
$
Unlike LASSO, the MCP penalty applies progressively less shrinkage to large coefficients, thereby reducing estimation bias while preserving sparsity.

Theoretical results for folded-concave penalized Cox regression suggest that, under suitable regularity conditions, MCP estimators can achieve oracle-type properties in high-dimensional settings \citep{bradic2011regularization}. Since the primary objective of this study is the computational implementation and empirical evaluation of MCP for time-dependent Cox regression, detailed asymptotic developments are omitted.





\subsection{Estimation Procedure for MCP-Penalized Cox Regression}
\label{sec:mcp_estimation}

To estimate the MCP-penalized time-dependent Cox model, we employ an iterative computational procedure that combines local linear approximation, active set strategy,coordinate descent optimization, and EBIC-based tuning parameter selection. At iteration $k$, the MCP penalty is locally approximated by
\[
p_{\lambda}(|\beta_j|)
\approx
p_{\lambda}(|\beta_j^{(k)}|)
+
p_{\lambda}'(|\beta_j^{(k)}|)
\left(
|\beta_j|-|\beta_j^{(k)}|
\right),\quad
p_{\lambda}'(t)
=
\lambda
\left(
1-\frac{t}{\gamma\lambda}
\right)_+,
\qquad
\gamma>1.
\]
This approximation transforms the original optimization problem into the weighted $\ell_1$-penalized objective function
\[
Q^{(k)}(\boldsymbol{\beta})
=
\ell^{B}(\boldsymbol{\beta})
-
\sum_{j=1}^{p}
w_j^{(k)} |\beta_j|,
\qquad
w_j^{(k)}
=
p_{\lambda}'\bigl(|\beta_j^{(k)}|\bigr).
\]

The resulting weighted problem is solved using coordinate descent. Based on a quadratic approximation of the Breslow partial log-likelihood, the coordinate-wise update is given by
\[
\beta_j^{(k+1)}
=
\mathcal{S}
\left(
\beta_j^{(k)}
+
\frac{
	U_j(\boldsymbol{\beta}^{(k)})
}{
	I_{jj}(\boldsymbol{\beta}^{(k)})
},
\;
\frac{
	w_j^{(k)}
}{
	I_{jj}(\boldsymbol{\beta}^{(k)})
}
\right),\quad
\mathcal{S}(x,\eta)
=
\mathrm{sign}(x)(|x|-\eta)_+
\]
denotes the soft-thresholding operator, and
$U_j(\boldsymbol{\beta})$ and
$I_{jj}(\boldsymbol{\beta})$
represent the score component and the diagonal element of the observed information matrix, respectively.

The complete iterative estimation scheme, including the updating strategy, warm-start initialization, active set strategy and convergence criterion, is summarized in Figure~\ref{fig:mcp_algorithm}. To select the regularization parameter, the final model is determined using the extended Bayesian information criterion (EBIC),
\[
\mathrm{EBIC}(\lambda)
=
-2\,\ell^{B}
\bigl(
\widehat{\boldsymbol{\beta}}(\lambda)
\bigr)
+
\log(d)\,df(\lambda)
+
2\gamma_{\mathrm{EBIC}}
\log(p)\,df(\lambda),
\]
where $d$ denotes the number of observed events and $df(\lambda)$ is the number of selected variables. The optimal tuning parameter is then chosen as
$
\widehat{\lambda}
=
\arg\min_{\lambda}
\mathrm{EBIC}(\lambda).
$

\section{Simulation Study}
\label{sec:simulation}

A Monte Carlo simulation study was conducted to evaluate the finite-sample performance of the proposed MCP-penalized estimator for variable selection in time-dependent Cox regression and to compare it with LASSO. Data were generated under the counting-process formulation 
$(\mathrm{start},\mathrm{stop},\mathrm{status})$,
assuming a constant baseline hazard function, $h_0(t)=1$.

The true coefficient vector included six active predictors,
$
\boldsymbol{\beta}_{01}
=
(1.2,0.8,0.5,-0.5,-0.8,-1.2)^T,
$
while the remaining coefficients were set to zero. Simulation scenarios considered sample sizes
$n\in\{200,500\}$ 
and predictor dimensions
$p\in\{0.5n,1.5n\}$,
covering moderate- to high-dimensional survival settings. Covariate processes were generated from multivariate normal distributions with an AR(1) correlation structure,
$
\mathrm{Cov}(Z_{ij},Z_{ik})=\rho^{|j-k|},
$
where $\rho\in\{0,0.5\}$.

Time-dependent covariates were generated over follow-up intervals, and censoring was introduced to obtain approximately 20\% censored observations. MCP estimation was carried out using the proposed estimation procedure described in Section~2.3, while LASSO estimation was implemented using the \texttt{glmnet} package \cite{simon2011regularization}. Each simulation setting was repeated $m=50$ times.

Overall, the two methods exhibit distinct variable-selection behaviors. LASSO consistently yields lower FP counts than MCP, reflecting its tendency to produce sparser models. For example, under $(n,p)=(600,900)$ with independent covariates $(\rho=0)$, the average FP was 0.10 for LASSO compared with 2.77 for MCP.

In contrast, MCP generally produces substantially fewer false negatives, particularly as the sample size increases. Under $(n,p)=(600,900)$ and $\rho=0$, the average FN was 0.09 for MCP versus 0.69 for LASSO. Similar patterns were observed across most moderate- and high-dimensional settings, indicating that MCP is more effective in retaining truly active predictors, whereas the stronger shrinkage imposed by LASSO may lead to the omission of important variables.

The reported standard errors suggest that the results are reasonably stable across Monte Carlo replications. In particular, the variability of FN decreases with increasing sample size, with this reduction being especially pronounced for MCP, indicating improved reliability in recovering active covariates in larger samples.

Correlation among covariates increased the difficulty of identifying active predictors, resulting in higher FN values in several correlated scenarios. Nevertheless, MCP continued to achieve lower FN rates than LASSO in most moderate- and large-sample settings.

From a computational perspective, the proposed MCP implementation demonstrated a clear advantage over LASSO. In the setting $(n,p)=(100,50)$, MCP required approximately 0.09 seconds, whereas LASSO required more than 7 seconds. This advantage persisted as the problem dimension increased. Even in the largest scenario considered, $(n,p)=(600,900)$, MCP completed estimation in approximately 36 seconds, compared with 49--51 seconds for LASSO. These findings indicate that the proposed estimation strategy, combining local linear approximation, coordinate descent, active-set updates, and warm starts, scales efficiently to high-dimensional time-dependent Cox regression problems.

Taken together, the results indicate that the proposed MCP procedure provides a favorable balance between variable-selection accuracy and computational efficiency. Although LASSO produces sparser models with fewer false positives, MCP substantially reduces false negatives and more effectively recovers truly active predictors while consistently achieving superior computational efficiency.

\section{Mayo Clinic PBC Data Analysis}
\label{sec:realdata}

The proposed MCP-penalized method was evaluated using the Mayo Clinic primary biliary cirrhosis (PBC) dataset \cite{Therneau2015}. After removing observations with missing values, 312 patients with longitudinal follow-up information were analyzed. The data were transformed into counting-process format using the \texttt{tmerge()} function to accommodate time-dependent covariates.

Continuous covariates were modeled using natural cubic splines and standardized prior to model fitting. MCP estimation was performed using the procedure described in Section~2.3, whereas LASSO estimation was implemented using the \texttt{glmnet} package \cite{simon2011regularization}. Predictive performance was evaluated using Harrell's concordance index and time-dependent AUC at selected follow-up horizons.

Table~\ref{tab:performance} shows that both MCP and LASSO achieved comparable predictive accuracy, with nearly identical C-index and AUC values. However, MCP required substantially less computational time, completing estimation in approximately 1.46 seconds compared with 18.27 seconds for LASSO.
