\section{Introduction}
The deep integration of social media into everyday life has created a new pattern in human interactions. This process, often described as the digitalization of modern society, has made it essential for researchers in different fields to study its structural effects and consequences. For this reason, researchers attempt to identify existing problems and report them to system administrators and developers. This helps improve the system and increases user satisfaction, which may attract more users to the platform.
To address attitudes, Natural Language Processing (NLP) has become a popular approach for analyzing people’s opinions because it can extract meaningful information from large amounts of textual data (\cite{Go:2009}). 
Sentiment Analysis is one of the NLP techniques that identifies and classifies the emotional polarity of text into categories such as positive, negative, or neutral. Sentiment analysis is widely used as a technique that combines methods from both machine learning (ML) and natural language processing (\cite{Yadav:2023}). 
For this purpose, we try to understand people’s emotions and opinions by using Facebook’s comments dataset. Overall, the dataset provides a comprehensive collection of public comments and captures different aspects of each recorded comment, including the time it was posted and the user ID. The dataset contains approximately 4 million rows and 8 columns. For this research, only the most recent 1 million rows of the dataset were utilized. The complete dataset spans the period from 2009 to 2023.
Various methodologies were used to assess the sentiment of the comments. A lexicon-based method using Text Blob to calculate polarity was implemented as a first step. A machine learning approach based on TF‑IDF feature extraction then converted the textual data into numerical form for sentiment classification by training a machine learning model with it. Finally, a Transformer-based model was also used not only to learn deeper contextual relationships within text but also to improve the overall performance of sentiment prediction.

A multi-faceted approach to sentiment analysis was adopted in this study whereby we combined the lexicon-based, machine learning, and deep learning approaches to sentiment analysis. The lexicon-based method formed a comprehensible benchmarking tool to determine the polarity of sentiments. The machine learning methods were used to model the linguistic patterns through feature engineering while the deep learning method allowed us to take advantage of the context semantics and latent structures. The evaluation of all the three techniques gave us insight into the balance between the computational efficiency, interpretability, and accuracy of the techniques in analyzing the dataset.

\subsection{Data Description: }
Facebook comments were collected for 14 years (2009-2023). The data set consists of 4 million observations and 8 distinct variables. In relation to the structure of data, the text review column (comments) is an unstructured text, and other columns, such as User ID, review rate, review likes, and review time, are structured.
Considering the size of the dataset, that’s why calculations take time, so to decrease the time, we selected a subsample of the corpus that contained one million observations and all variables.

\subsection{Text Preprocessing:}
Since social media is an informal platform for discourse, the corpus we collected also contained a lot of noise, such as slang, irregular punctuation, and non-textual information. As a result, this data underwent text cleaning and normalization to enhance feature extraction by the model.
Eliminating emoji, links, and marks from comments to clarify the text to model.
The date column has been corrected too; its correct form is as follows:
Year-month-day hour- minute-second 

\subsection{Manual Annotation and Gold Standard Creation:}
To establish a reliable ground truth for model evaluation, a representative subset of the collected Facebook comments was randomly sampled for manual annotation. This ‘Gold Standard’ dataset was labeled by human experts into sentiment categories (Positive, Negative, and Neutral). The manually labeled data served two primary purposes: first, to provide a high-quality training set for the supervised Machine Learning models (e.g., Logistic Regression), and second, to act as a benchmark for calculating performance metrics such as Accuracy, Precision, Recall, and F1-score across all implemented sentiment analysis approaches.
Due to how many observations we need to, we use the Cochran sampling formula, that it consistent Error rate equal to 3\%, Z0.95, and p is the proportion of the population (generally taken as 0.5).
\begin{align}
	n_0 &= \frac{Z^2 p(1 - p)}{E^2} \\
	n &= \frac{N n_0}{N + n_0 + 1}
\end{align}

\subsection{Implementation of sentiment classification models:}
In a sentiment context, a lot of methods can be conducted so that we can compare the methods and choose the best method that fits the dataset and has good efficiency.

\subsubsection{Lexicon-based approach $->$ TextBlob method:}
Early studies in sentiment analysis mainly relied on lexicon-based approaches, which rely on predefined dictionaries to define the sentiment of a comment or text. Polarity criteria assign the value of text in the interval [-1,1] and classify text into three categories: negative, positive, and neutral. TextBlob is considered one of the lexicon-based approaches. This model is computationally efficient, simple to implement, and does not require any training dataset, but its limitation can be low accuracy, cannot understand the context and sarcasm very well (\cite{Singhal:2016}). There are several issues with this approach, for instance, most of the time, the presence of more positive words does not necessarily mean it is a positive comment, so sometimes it is impossible to recognize sentiment using a lexicon-based approach (\cite{Gudivada:2015}).
Despite these limitations, the TextBlob method is useful as a simple baseline approach and serves as a good starting point for sentiment analysis modeling. 

\subsubsection{Machine Learning $->$ logistic Regression:}
Machine Learning (ML) techniques for sentiment classification gain interest because of their capabilities to model (\cite{Boiy:2008}). The ML approach trains a model to automatically learn sentiment patterns from labeled data or Gold Standard Creation.
TF-IDF (Term Frequency–Inverse Document Frequency) is a statistical method used in NLP and information retrieval to evaluate how important a word is to a document in relation to a larger collection of documents. TF-IDF combines two components:
TF means Term Frequency, which measures how often a word appears in a document.
\begin{equation}
	\text{TF (t, d)} = \frac{\text{Number of times term } t \text{ appears in document } d}{\text{Total number of terms in document}}
\end{equation}

IDF means Inverse Document Frequency, Which Reduces the weight of common words across multiple documents while increasing the weight of rare words.

\begin{equation}
	\text{IDF (t, D)} = \log \frac{\text{Total number of documents in corpus } D}{\text{Number of documents containing term } t}
\end{equation}

And finally, we have:
\begin{equation}
	\text{TF-IDF (t, d, D)} = \text{TF (t, d)} \times \text{IDF (t, D)}
\end{equation}

Consequently, Term Frequency--Inverse Document Frequency aids Logistic regression to classify the comments or text into three categories.

\subsubsection{Deep Learning $->$ transformers:}
Neural networks have recently become a very popular topic of research in the field of NLP, especially in sentiment analysis. Once a suitable neural network architecture is designed for the problem at hand, a solution to the classification problem can be obtained using deep learning models(\cite{Singhal:2016}). A strength of the deep learning models is no demand for carefully optimized hand-crafted features. Instead of the features, they take word embeddings as input, which contain context information, and the intermediate layers of the neural network learn the features during the training phase itself. This means that a necessity, which is at the base of the traditional classification models, is no longer required for the functioning of deep learning models (\cite{Singhal:2016}).
